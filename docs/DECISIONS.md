# Decisions

External facts are marked **VERIFIED** when this repository's build read the named source, and **ASSUMED** when the code picks a convention the source does not fix.

## Extra modules

These are not in the original file list. Each one keeps a rule testable or keeps student text out of HTML strings.

| Module | Why |
| --- | --- |
| `js/core/client-check.js` | Browser and device gate. Unit-tested without a window. |
| `js/core/py-session.js` | Replay delay, run timeout, and output cap as a pure state machine. |
| `js/ui/dom.js` | `createElement` plus text nodes. UI files do not assemble HTML strings. |
| `tools/serve.mjs` | Zero-dependency static server mounted at `/lab-exam/`. |
| `CONFIG_VERSION` | Copied into each report so a teacher can see which settings file produced it. |

| URL parameters `embed=1`, `proto=json`, `spin=1`, `configure=1`, `libraries=1`, `noSaveBtn=1`, `noExitBtn=1`, `saveAndExit=0`. | VERIFIED | Same embed-mode page. `noSaveBtn=1` replaces Save with Save and Exit, and `saveAndExit=0` hides that button. |
| JSON protocol: `{event:'configure'}` then `{action:'configure', config}`; `{event:'init'}` then `{action:'load', xml, autosave:1}`; `{event:'autosave', xml}` on change; `{action:'export', format:'png', background, border}` returns `{event:'export', data, xml}`. | VERIFIED | Same embed-mode page. `background` is a colour string and `border` is pixels for `png`. Messages are JSON-encoded, so the page sends `JSON.stringify` and accepts either a string or an object inbound. |
| `defaultLibraries` is a semicolon-separated library list. `enabledLibraries` is an array. `enableCustomLibraries: false` disables open and new library. `suppressNewWindows: true` avoids `window.open`. `override: true` ignores saved editor settings. `sidebarWidth` is the shape-list width in pixels. A `libraries` entry with `expand: true` opens that palette. | VERIFIED | https://www.drawio.com/doc/faq/configure-diagram-editor read 2026-11-03. The page sets `override: true`, `sidebarWidth: 232`, `defaultLibraries: "exam-uml;general;uml"`, and an expanded `exam-uml` palette. Saved settings on `embed.diagrams.net` can store a shape-list width of 0, and the built-in UML palette is created collapsed under General. |
| `hideMenuItems` can include `"plugins"`. No documented key turns plugins off completely. | VERIFIED | The configure page's `hideMenuItems` example includes `"plugins"`. The page hides that menu item and does not claim plugins are disabled. |
| Holding Escape about two seconds still exits fullscreen when Keyboard Lock includes Escape. Keyboard Lock is Chromium-only. | ASSUMED | The product prompt cites the WICG keyboard-lock specification. This build did not re-read that specification. Firefox is allowed through the gate and told that Escape cannot be locked. |
| `requestFullscreen` must run in the click turn, before the first `await`. | VERIFIED | A user activation does not survive an `await` that fetches the bank or runs PBKDF2. The click handler validates synchronously, requests fullscreen, then loads the bank. Spec section 5 lists load before fullscreen. This order is the one browsers accept. If load or assignment fails, the page exits fullscreen and stays on the gate. A register number that already submitted skips fullscreen and shows the receipt. |
| First four bytes of SHA-256 are a big-endian uint32, then `% n + 1`. | ASSUMED | The assignment rule says "as uint32" and does not name the byte order. `assign.js` uses big-endian (`DataView.getUint32(0, false)`). Recompute with the same function. |
| Question-bank key uses PBKDF2-SHA256, 310000 iterations, AES-GCM, 16-byte salt, 12-byte IV. | VERIFIED | WebCrypto algorithm names. The iteration count is this app's choice above the required 300000. A wrong code becomes exactly `Invalid exam code`. |
| Receipt is the first 12 hex characters of SHA-256 of the canonical payload, grouped `ABCD-EF01-2345`. The hash and receipt are outside the hashed object. | VERIFIED | Implemented in `js/core/report.js` and checked by `node --test`. |
| `<` inside the embedded submission JSON is written as `\u003c`. U+2028 and U+2029 are escaped. The report's own `</script>` tag remains. | VERIFIED | `embedJson` in `js/core/report.js`. The report test extracts the code `print('</script>')` back out of the JSON. |
| PNG images in the report are accepted only when the URI matches `data:image/png;base64,` plus base64 characters. | VERIFIED | `isPngDataUri` in `js/core/report.js`. |
| localStorage quota: drop report HTML and diagram PNG bytes, then retry once. | ASSUMED | Browsers throw `QuotaExceededError` with no standard partial-write API. The in-memory download at submit still has the images. |
| Focus polling does not append another `FOCUS_LOST` while the overlay is already up. | ASSUMED | The spec asks for a 1 second `hasFocus` backup. Logging that poll on every tick while the overlay is up would fill the report. One incident already covers the screen. |
| Invigilator unlock sets the incident counter back to 0 and clears the overlay. The timer is unchanged. | ASSUMED | The spec says the PIN clears the locked state. It does not say whether the count stays at the maximum. Resetting lets the student continue. The action is logged as `INVIGILATOR`. |
| Second-tab owner never yields. A new tab blocks itself. `SECOND_TAB` is scored only after an exam session is active. A localStorage heartbeat covers the case where `BroadcastChannel` loses the race. | ASSUMED | The spec says the new tab shows the message and does nothing else. The owner-stays rule is the smaller behaviour. |
| Force question is stored in localStorage and applied on the next gate entry. The same question resumes. A different question clears code, diagrams, inputs, and runs, and keeps the original start time and log. | ASSUMED | The spec says the override is stored locally and applied at the next gate entry. |
| `REGNO_PATTERN` is `^[A-Z0-9][A-Z0-9/-]{2,31}$` after normalisation. | ASSUMED | The college format was not specified. Change the pattern in `config.js`. |
| Empty diagram means no `mxCell` beyond the two root cells (ids 0 and 1). | ASSUMED | draw.io's blank document uses those two cells. The count is `mxCell` tags minus 2. |
| Iframe `sandbox` is `allow-scripts allow-same-origin allow-forms allow-modals`, with `referrerpolicy=no-referrer`. | VERIFIED | Required by the product prompt. `allow-popups` is omitted. `suppressNewWindows` is also set. Not tested against a live embed in this environment. |
| SharedArrayBuffer is not used for `input()`. | VERIFIED | GitHub Pages cannot set COOP/COEP, and those headers would block the draw.io frame. Replay is implemented in `py/runner.py`. |
| `NeedInput` extends `BaseException`. `random.seed(12345)` runs before student code. `os.system('cls'|'clear')` clears the console. | VERIFIED | `py/runner.py`, covered by `tests/runner.test.mjs`. |
| Friendly import message for numpy, tkinter, matplotlib, and pygame: "Only the standard library is available in this exam". Other blocked modules say "Import of {name} is disabled in this exam." | VERIFIED | `py/runner.py` and the runner tests. |
| PostMessage from draw.io is accepted only when `origin === DRAWIO_ORIGIN` and `source` is that iframe's `contentWindow`. | VERIFIED | `js/ui/uml-tab.js`. |
| Inactive diagram iframe uses `visibility: hidden`, not `display: none`. | VERIFIED | `css/app.css` class `is-inactive`. Whether the editor lays out after being shown was not run against a live embed. |
| Ctrl+Alt+Shift+I opens the invigilator panel and is not scored as `DEVTOOLS_KEY`. | VERIFIED | `minorKey` in `js/ui/lockdown-ui.js`, covered by `tests/storage-client.test.mjs`. |
| Sample exam code `exam-demo` and scaffold PIN `lab-invigilator` were public (both retired: the exam code with the question bank, the PIN replaced on 2026-11-05). | VERIFIED | Written into this file's sibling README and into `config.js` comments. They are not secrets. |
| The report is a PDF built with jsPDF 4.2.1. The sealed submission JSON is base64 in the XMP metadata stream, between `LABEXAM-SUBMISSION-1:` and `:END-LABEXAM`. | VERIFIED | `jsPDF.API.addMetadata` writes that stream without a filter even with `compress: true` (read in `node_modules/jspdf/dist/jspdf.es.js`). `tests/report.test.mjs` round-trips it and detects an edited payload. | Report times use `Intl` `en-IN` in the student's browser time zone, for example `3 Nov 2026, 3:43:45 pm IST`. The build id is kept in the data, not printed. | ASSUMED | Lab PCs are expected to be set to IST. The ISO times stay in the embedded data. |
| Questions are on paper. The site has no question bank, no exam code, and no assignment. The student types the question number (1 to `QUESTION_COUNT`) at sign-in; it is kept on resume, and the invigilator's correction replaces it without clearing work. | ASSUMED | The teacher hands out questions individually. The rows above about assignment, the question-bank key, the sample exam code, and force question describe the removed design and are kept for history. |
| Google sign-in uses Google Identity Services (`https://accounts.google.com/gsi/client`), loaded only when `GOOGLE_CLIENT_ID` is set. The page reads the ID token's claims for name and email and does not verify its signature. | ASSUMED | Google documents the GIS button and the ID token. Not run against a real client ID in this build. The page check only fills the form; trust comes from the server. |
| The Apps Script verifies each start's ID token with `https://oauth2.googleapis.com/tokeninfo` (audience, `email_verified`, `hd`), then returns an HMAC-SHA256 session token signed with a per-script secret. Submissions need that token, not the ID token, because ID tokens expire after about an hour and the exam lasts two. | ASSUMED | `tests/google.test.mjs` runs `Code.gs` with stand-ins for Google services, and a browser run drove the real page against it. | The page posts to the web app as `text/plain` JSON, so the browser sends a simple request with no CORS preflight. | ASSUMED | Apps Script cannot answer a preflight. | The web app is deployed "Execute as: Me, Who has access: Anyone". | The Apps Script upload (Drive folder, Sheet, faculty sharing) was removed on 2026-11-05. Students upload the PDF to a Google Form. | ASSUMED | The teacher prefers a Google Form. | The PDF is reproducible: jsPDF's creation date is set to `submittedAt` and its file id to the first 32 hex characters of the hash, and the title, course, and time zone it was drawn with are embedded next to the sealed data. | A self-made PDF cannot be unforgeable: the code is public and runs in the student's browser.
